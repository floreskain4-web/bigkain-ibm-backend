THE KEY BOUNDARY

Built to stay non-custodial.

The dashboard requests only public health and market data. BigKain does not receive private keys or seed phrases, does not sign transactions, and has no broadcast endpoint. Any wallet signing in a future flow must happen locally, after explicit user approval.
